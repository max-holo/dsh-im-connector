# v1.6.6 — 钉钉 / 企微 MCP 连接器

MCP 连接器：让 AI Agent 直接使用**钉钉（dws）**与**企业微信（wecom-cli）**——发消息、写日报、建待办、订日程、批审批、读写文档，扫码登录即用。

## 📦 安装 / 升级

```powershell
# DSH：插件页 → 发现 → 搜索 im-connector → 安装；或
dsh plugin --profile web add im-connector@1.6.6
# 升级后重启 dsh web
```

通用 MCP 客户端：

```json
{ "mcpServers": { "im": { "command": "npx", "args": ["-y", "im-connector@1.6.6"] } } }
```

**登录**：设置页点「登录」——企微出二维码扫码；钉钉页内二维码（设备码）或拉起浏览器授权。

## 🔧 环境变量（dws 获取相关）

| 变量 | 作用 |
|---|---|
| `DINGTALK_DWS_NO_DOWNLOAD=1` | 关闭自动下载（离线/内网） |
| `DINGTALK_DWS_DOWNLOAD_BASE=<URL>` | 下载镜像前缀（支持 http） |
| `DINGTALK_DWS_VERSION=v1.0.68` | 固定下载版本 |
| `IM_CONNECTOR_CACHE_DIR` | 二进制缓存目录 |

## ⚠️ 升级注意

- 国内网络直连 GitHub Release 可能超时：设 `DINGTALK_DWS_DOWNLOAD_BASE` 镜像，或用官方 install 脚本装一次（优先命中，不触发下载）
- 自 ≤1.6.x 升级无破坏性变更
