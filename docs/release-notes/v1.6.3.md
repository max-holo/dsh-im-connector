# v1.6.3 — 开箱即用的钉钉/企微 MCP 连接器

MCP 连接器：让 AI Agent 直接使用钉钉（dws）与企业微信（wecom-cli）——发消息、写日报、建待办、订日程、批审批、读写文档，扫码登录即用。

本仓库首个公开 Release。npm 已发布同版本：[`im-connector@1.6.3`](https://www.npmjs.com/package/im-connector)。

---

## ✨ 本版本亮点

### 1. macOS / Linux 开箱即用（1.6.0）

不再要求手工安装 `dws`：包内没有对应平台二进制时，首次调用自动从官方 GitHub Release 下载（约 17–24MB，仅一次），用同一 release 的 `checksums.txt` 校验 sha256 后解压到用户缓存目录，之后直接复用。

- Windows 继续随包携带兜底二进制，离线可用
- 解析优先级：`DINGTALK_DWS_BIN` → 官方独立安装（`~/.local/bin`）→ npm 全局 → 本地依赖 → 包内兜底 → **按需下载** → PATH

### 2. 失败可修复，而不是一句 ENOENT（1.6.1）

CLI 不可用时，`info` 返回 `available: false` + `download.error`（真实原因：超时/连接拒绝/校验不符）+ `hint`（四条可照做的修复方式）；`run`/`login` 的失败结果附同一份 `hint`。服务器提示词也加了「把 hint 转述给用户，不要反复重试」的指引。

### 3. 设置页 GitHub 入口（1.6.2）

「IM 连接器」设置页头部右侧新增 GitHub 图标，点击直达本仓库。

## 📦 安装 / 升级

**DSH（DeepSeek Harness）用户**：

```powershell
# 插件页 → 发现 → 搜索 im-connector → 安装；或命令行：
dsh plugin --profile web add im-connector@1.6.3
# 已安装用户：插件页 → 已安装 → im-connector → 更新
```

安装后**重启 dsh web**，然后对模型说「看下 IM 连接器状态」即可自检。

**通用 MCP 客户端**（Claude Desktop 等）：

```json
{
  "mcpServers": {
    "im": {
      "command": "npx",
      "args": ["-y", "im-connector@1.6.3"]
    }
  }
}
```

**登录**：设置页点「登录」扫码（企微）；钉钉在页面内出二维码（设备码模式）或拉起浏览器授权。

## 🔧 新增环境变量

| 变量 | 作用 |
|---|---|
| `DINGTALK_DWS_NO_DOWNLOAD=1` | 关闭自动下载（离线/内网） |
| `DINGTALK_DWS_DOWNLOAD_BASE=<URL>` | 下载镜像前缀（支持 http，国内网络建议设置） |
| `DINGTALK_DWS_VERSION=v1.0.68` | 固定下载版本 |
| `DINGTALK_DWS_DOWNLOAD_TIMEOUT_MS` | 下载墙钟超时（默认 180000） |
| `IM_CONNECTOR_CACHE_DIR` | 二进制缓存目录（默认 `~/.cache/im-connector`，Windows 为 `%LOCALAPPDATA%\im-connector`） |

### 1.6.3
- README 移除对第三方插件的引用，范围说明改为中性地描述「Agent → 渠道」单向定位

### 1.6.2
- 设置页头部新增 GitHub 仓库图标链接

### 1.6.1

- 解析链新增 PATH 识别（brew / scoop / 手工安装不再被误判，也不会白下载）

### 1.6.0
- 官方二进制按需下载：macOS（amd64/arm64）、Linux（amd64/arm64）、Windows arm64
- sha256 校验 + 用户缓存 + 指针文件，下载一次后离线复用
- MCP `toolCallTimeoutMs` 提升至 180s，覆盖首次下载耗时
- 下载走 stderr 输出诊断，不污染 MCP 的 stdout JSON-RPC 通道
