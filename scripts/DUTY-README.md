# 值班提醒定时任务

向「平台产品群」发送值班提醒并 @ 每个休息日的值班人。值班人按 **杨春艳 → 余海 → 丁桐 → 马玄** 循环、**每人一天**，下一个休息日从 **杨春艳** 开始。

## 触发规则

某天 D 为「触发日」当且仅当：D 是工作日，且 D+1 是休息日。

- 休息日 = 周六/周日（非调休上班日）或法定节假日（含调休放假日）
- 工作日 = 周一~周五（非法定节假日）或调休上班日（周末补班）

即：每个周末前的最后一个工作日、每个法定节假日开始前的最后一个工作日各触发一次。

## 消息内容

- 标题：`值班提醒`
- 正文：每个休息日一行，格式 `值班日期（周X）：@值班人员`，例如：

```
10月17日（周六）：@杨春艳
10月18日（周日）：@余海
```

节假日连休时按天依次轮换（如 7 天假为 杨→余→丁→马→杨→余→丁）。

## 文件

| 文件 | 作用 |
|---|---|
| `scripts/duty-reminder.mjs` | 执行器：计算触发日/值班人、构造消息、调用 dws 发送 |
| `scripts/duty-config.json` | 配置：群、值班轮换、节假日日历、消息模板 |

## 手动运行

```bash
node scripts/duty-reminder.mjs --list --days 60          # 列出未来 60 天触发日与值班人
node scripts/duty-reminder.mjs --dry-run --date 2026-10-16  # 预览某触发日会发送的内容（不真正发送）
node scripts/duty-reminder.mjs --send                    # 若今天是触发日则真正发送
```
